# Inflation Trend Analyzer

This project visualizes WPI and CPI inflation trends across multiple years using public datasets (MOSPI, RBI).

## Features

✅ Interactive line plots for WPI/CPI  
✅ Highlights key economic events  
✅ Understands cyclical inflation behavior

## How to Use

1. Place your dataset (`inflation_data.csv`) in the project folder  
2. Run `inflation_trends.py` to generate visualizations

## Requirements

- Python 3  
- pandas, matplotlib, seaborn
